# learning-without-curriculum

**Exploring Independent Learning Trajectories in Technical Skills Acquisition**

This repository contains a research paper and supporting materials on how students learn technical skills outside formal education, focusing on the "Need–Build–Validate" loop and the role of AI-assisted learning.

[Source](https://github.com/ruthwwikreddy/learning-without-curriculum) · Built by [Ruthwik Reddy](https://www.ruthwikreddy.live/)

MIT licensed · Key technical highlight: Auto-ethnographic study of independent learning trajectories in technical skills acquisition.

## 1. What learning-without-curriculum does

| Capability | Detail |
|---|---|
| Analyzes independent learning trajectories | Uses auto-ethnographic study to examine how students learn technical skills outside formal education. |
| Identifies key patterns and triggers | Finds that the "Need–Build–Validate" loop is a crucial part of independent learning. |
| Examines the role of AI-assisted learning | Investigates how AI tools influence the learning process. |
